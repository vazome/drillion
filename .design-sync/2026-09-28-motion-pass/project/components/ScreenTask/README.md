The task page mid-attempt: spec on the left, editor on the right, grading under it.

- 48px top bar with a breadcrumb instead of the sidebar.
- Header on one line: number, title, difficulty, path, status, then the timer and Abandon. No source credit, no "No prereqs", no "Opens N tasks".
- Spec pane in the authored order, a Stuck? bar pinned to its foot with the hint countdown and the solution gate.
- File tabs: yours first with a `yours` pill; context files `read-only`.
- Grading bar: submits and seed, Run (secondary, Ctrl Enter), Submit (primary, Ctrl Shift Enter).
- A failed Run says no attempt was used and nothing moved, then what passed and the one rule that failed.
